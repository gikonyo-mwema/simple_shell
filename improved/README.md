# Improved snapshot

This directory is a small snapshot associated with the shell project, not a
second buildable implementation. It contains [`.vimrc`](.vimrc), which sets
the editor's tab and indentation widths. No C source files or build
instructions are included here.

The compiled `hsh` executable that was previously tracked in this directory
has been removed from version control. Build the maintained implementation
from the repository root as described in the [main README](../README.md).
